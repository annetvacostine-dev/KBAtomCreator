# KBAtomCreator
Создатель атомов для КБ. Создаёт Атомы на основе существующих. Позволяет быстро получить копию объекта и все нужные файлы для работы.


# Сборка и запуск проекта

Для разработки использовалась Visual Studio 2026.

Клонируйте проект из репозитория https://github.com/annetvacostine-dev/KBAtomCreator.git .

Запустите файл решения в Visual Studio KBAtomCreator.sln.


# Инструкция по использованию

Руководство пользования

## ✅ Подготовка к работе
- 1 (выполняется один раз) Распакуйте ресурсы king's bounty в отдельную папку. Или скачайте их по ссылке [Папка с ресурсами на Яндекс диске](https://disk.yandex.ru/d/tDYFrtjvQQlMlg).


- 2. Выберите папку с ресурсами King's Bounty, перетащив исходную папку или нажав на "...". Настроенная папка сохранится и будет выбрана при следующем запуске.

(Instructions/inst1.png)

## ✅ Основная часть.
- 1. Выберите исходного юнита из  списка "Список атомов".
(Instructions/inst0.png)

- 2. На вкладке общие "Характеристики" Можно менять исходные характеристики. Обратите внимание, что не все исходные характеристики можно менять! Часть из старых характеристик не пойдёт в новый сохраненный атом.
(Instructions/inst2.png)

- 3. На вкладке "Описание и способности" заполните "Название существа"(когда оно одно в армии и когда несколько). Добавьте способности и таланты.
(Instructions/inst3.png) 
(Instructions/inst4.png)

- 4. Нажмите "Сохранить нового юнита" для сохранения результатов и выберите каталог! Автоматически сгенерированное название получившегося атома можно изменить.
(Instructions/inst5.png)

- 5. После этого откроется вкладка с результатами где вы можете смотреть, а также открывать полученные файлы. Вы также можете открыть папку с результатами в проводнике.
(Instructions/inst6.png)
